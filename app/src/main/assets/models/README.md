# 3D pet model

| File | Notes |
|------|--------|
| `octobuddy.glb` | Brand-matched stylized octopus used by SceneView (navy mantle, cyan glow eyes/rings, copper undersides + suckers) |

## Source & license

**Original work created for OctoBuddy (CC0 1.0 / public domain).**

Procedurally authored low-poly GLB regenerated by `tools/generate_octobuddy_glb.py`
so the mesh stays reproducible. Colors were sampled from
`app/src/main/res/drawable-nodpi/octobuddy_pet.png` (Evil0ctopus mark): deep navy body,
electric cyan emissive eyes / ring spots, copper/tan tentacle undersides with sucker discs.

Silhouette goals vs the 2D icon: bulbous peaked mantle, slanted cyan eyes, eight radiating
curled tentacles, ring spots on mantle + outer tentacles. Hatchling → Adult still uses
**scale-only** evolution (`PetStage.modelScale`) on this single mesh (head/eyes are slightly
oversized so small hatchling scale still reads).

No third-party mesh was redistributed.

### Regenerate

```bash
python3 tools/generate_octobuddy_glb.py
# writes app/src/main/assets/models/octobuddy.glb
```

Requires `numpy`. Prefer CC0 / free licenses only if you replace this file — keep path
`models/octobuddy.glb` (or update `Pet3DView.kt`) and note attribution here.
