# Models

`octobuddy.glb` is an optional brand-colored stylized octopus (CC0), generated by
`tools/generate_octobuddy_glb.py`.

**OctoBuddy v0.6+ uses the 2D brand PNG as the hero pet** (`res/drawable-nodpi/octobuddy_pet.png`)
for brand fidelity. SceneView / Filament is not a runtime dependency. Keep this GLB if you
want to experiment with 3D environments later; do not ship it as a replacement for the mark.
