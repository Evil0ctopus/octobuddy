# Brand assets

Octopus artwork is **Evil0ctopus** (Evil0ctopus) brand mark.

| File | Notes |
|------|--------|
| `brand-mark.jpg` | Preferred square mark (source for the in-app pet) |
| `brand-icon.jpg` | Larger brand icon |
| `favicon.jpg` | Small favicon-style crop |
| `github-avatar.jpg` | GitHub avatar crop |

The Android drawable `app/src/main/res/drawable-nodpi/octobuddy_pet.png` is derived from `brand-mark.jpg`.

## 3D pet

The in-app animated pet is a **SceneView** GLB at `app/src/main/assets/models/octobuddy.glb`
(original procedural octopus, CC0 — regenerated by `tools/generate_octobuddy_glb.py` to match
this brand mark's navy / cyan / copper silhouette). See `app/src/main/assets/models/README.md`.
The flat PNG (`octobuddy_pet.png`) remains as a load-failure fallback only.
